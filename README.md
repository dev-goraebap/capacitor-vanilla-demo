## Features

### ✔ Do Capacitor
- 📷 카메라 – 기기 카메라로 사진 촬영
- 💾 로컬 저장소 – 저장 및 불러오기
- 📂 파일 시스템 – 파일 저장 및 관리
- 🔄 공유하기 – 네이티브 공유 기능 사용
- 📳 햅틱 피드백 – 진동으로 사용자 경험 향상
  
### ✔ No FE Framework
VanillaJS + Web Components로 가볍고 심플한 구조
